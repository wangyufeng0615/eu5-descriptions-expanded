# Descriptions Expanded: Countries, Cultures, Dynasties & More

English and Simplified Chinese descriptions for 7,075 countries, dynasties, cultures, religions, gods, holy sites, languages and more in Europa Universalis V, shown at the bottom of their tooltips.

- Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3838927963
- Manual download: [latest release](https://github.com/wangyufeng0615/eu5-descriptions-expanded/releases/latest). Extract the ZIP into `Documents\Paradox Interactive\Europa Universalis V\mod\` so that you have `mod\descriptions_expanded\`, then enable the mod in Mods and DLC. Don't enable it together with the Workshop copy.

## 描述扩展：国家、文化、王朝及更多

为 EU5 的 7,075 个国家、王朝、文化、宗教、神祇、圣地、语言等对象补上中英文介绍，显示在鼠标悬停浮窗底部。

- 创意工坊：https://steamcommunity.com/sharedfiles/filedetails/?id=3838927963
- 手动下载：[最新版本](https://github.com/wangyufeng0615/eu5-descriptions-expanded/releases/latest)。把 ZIP 解压到 `文档\Paradox Interactive\Europa Universalis V\mod\`，解压后应有 `mod\descriptions_expanded\`，再在“模组和 DLC”里启用。不要和创意工坊订阅的那份同时启用。
