# Descriptions Expanded: Countries, Cultures, Dynasties & More

English and Simplified Chinese descriptions for 7,075 countries, dynasties, cultures, culture groups, religion groups, religions, religious schools, religious aspects, gods, chivalric orders, holy sites, languages and language families in Europa Universalis V. Hover over one of them; the description is at the bottom of the tooltip. The game language picks English or Chinese. Where the game already has a description, it is kept and the new text follows it as extra paragraphs.

Dynasties show their description through the dynasty head, so a dynasty with no living member has none.

Manual install: extract the release ZIP into `Documents\Paradox Interactive\Europa Universalis V\mod\` so that you have `mod\descriptions_expanded\` (keep the hidden `.metadata` folder), then enable the mod in Mods and DLC. Do not enable a manual copy and the Workshop copy together.

The descriptions were written with AI assistance from published sources, mostly Wikipedia, matched to the game's objects and checked by automated and manual review. Corrections are welcome in the Workshop comments. The mod's new description text is CC BY-SA 4.0, tools are MIT; see LICENSE and CREDITS.md. Per-entry sources are in `sources/sources.jsonl`.
